ChipAgents Web – Voice Add-on

Install (one time, Edge or Chrome):

  1. Show the favorites/bookmarks bar: Ctrl+Shift+B
  2. Drag this button onto the bar: 🎙 ChipAgents Voice
  3. If dragging doesn't work: , add a new favorite, and paste it into the URL field.

Use: open the hub (http://localhost:4242/hub), then click 🎙 ChipAgents Voice. A small voice panel appears at the bottom right. Click the bookmark again to hide or show it. The add-on stays loaded until you reload the page. After a reload, click the bookmark again.

🎤 / Alt+MStart or stop dictation into the message box. Press Enter to send.
🔊 / 🔇Turn auto-read of finished replies on or off (saved).
▶ / Alt+RRead the last reply aloud.
⏹ / Alt+SStop speaking.
ATurn larger hub text (110%) on or off (saved, on by default). The header logo is always shown larger.
The first time you use the mic, the browser asks for microphone permission for each port (4242, 4243, …).
Voice input uses the browser's speech service, which sends your dictated audio to the browser vendor's cloud (Google or Microsoft).
Voice output uses only offline Windows voices (for example, Zira or David), so reply text stays on your PC. Code blocks and tables are skipped when reading.
